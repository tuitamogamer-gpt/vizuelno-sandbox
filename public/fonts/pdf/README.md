# Fonts embedded in PDF exports

Noto Sans, SIL Open Font License 1.1 (see OFL.txt).
Source: https://github.com/google/fonts/tree/main/ofl/notosans

Regular (400) and Bold (700) are static instances at width 100, created from
NotoSans[wdth,wght].ttf with fontTools.varLib.instancer. They retain Latin,
Latin Extended and Cyrillic glyphs. No external font request is needed at export.
The project's own selected fonts are rendered separately in the logo and specimens.
